# vim-brackets

括弧やブラケットを補完するVimプラグインです。

カーソル位置の前後の文脈に応じて適切に補完します。また、文脈に応じて括弧やブラケットに対するスペースキーやバックスペースキーの挙動を変更します。

## インストール

特別な設定は必要なく、プラグインをダウンロードするだけです。以下はvim-plugでインストールする場合の例です。

```vim
Plug 'ontheroad/vim-brackets'
```

## どのように機能しますか？

前後の文脈によって補完される場合とされない場合があります。

### 括弧のルール

機能するための条件は以下の通りです。

- カーソルが `()`、`{}`、`[]`、`<>` の内側にある場合

- カーソルが `""`、`''`、` `` ` の内側にある場合

- カーソルの右側が空の場合

動作します...

（`|` はカーソル位置です）

| 開始時    | キー  | 入力後      | 有効化 |
|:------ |:--- | -------- | --- |
| \|     | (   | (\|)     | yes |
| (\|)   | )   | ()\|     |     |
| (\|)   | (   | ((\|))   | yes |
| "\|"   | (   | "(\|)"   | yes |
| \|hoge | (   | (\|hoge  |     |
| hoge\| | (   | hoge(\|) | yes |
| ho\|ge | (   | ho(\|ge  |     |

`{}`、`[]`、`<>` も同様です。

### ブラケット

機能するための条件は以下の通りです。

- カーソルが `()`、`{}`、`[]`、`<>` の内側にある場合

- カーソルが `""`、`''`、` `` ` の内側にある場合

- カーソルの両側が空白の場合（上記を除く）

| 開始時    | キー  | 入力後     | 有効化 |
|:------ |:--- |:------- | --- |
| \|     | "   | "\|"    | yes |
| "\|"   | "   | ""\|    |     |
| hoge\| | "   | hoge"\| |     |
| \|hoge | "   | "\|hoge |     |
| ho\|ge | "   | ho"\|ge |     |
| (\|)   | "   | ("\|")  | yes |
| [\|]   | "   | ["\|"]  | yes |
| <\|>   | "   | <"\|">  | yes |
| {\|}   | "   | {"\|"}  | yes |

### <BS> キー

| 開始時         | キー   | 入力後       |
| ----------- | ---- | --------- |
| (\|)        | <BS> | \|        |
| ( \| )      | <BS> | (\|)      |
| xxx \|= xxx | <BS> | xxx\|=xxx |
| xxx = \|xxx | <BS> | xxx=\|xxx |

### <SPACE> キー

| 開始時       | キー      | 入力後         |
| --------- | ------- | ----------- |
| (\|)      | <SPACE> | ( \| )      |
| xxx\|=xxx | <SPACE> | xxx \|= xxx |
| xxx=\|xxx | <SPACE> | xxx =\| xxx |
